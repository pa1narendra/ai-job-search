## Rate guidance

Your Indian floor is 9-15 LPA (≈ $11k-18k/yr). Marketplace remote contracts are paid in USD/hour
and clear that easily:

- A **$25/hr** contract at 40 hrs/week ≈ **$50k/yr** — already ~3-4x your floor.
- Mid-level full-stack on these platforms typically lands **~$20-40/hr**; strong performers higher.

**Suggested opening rate: $25-35/hr.** Start around $28-30/hr; you can adjust after you see what
matches come in. Some platforms (Turing, Lemon.io) set or negotiate the rate for you — let them
anchor, then counter using the value framing above. Never quote your Indian LPA number to these
platforms; quote an hourly USD rate.

### 1. Lemon.io  — *best first target*
- **Fit:** mid-level full-stack JS/TS is their core. We already saw a React/Node role from them.
- **Process:** profile → short screening call (English + experience) → technical interview → matched.
- **Tip:** Lead with the 1M+ messages / sub-500ms result; they sell devs on concrete impact.

### 2. Arc.dev
- **Fit:** remote full-stack roles, India-friendly. Permanent and contract.
- **Process:** profile + skills + (sometimes) async coding assessment; HireAI matches you.
- **Tip:** Complete 100% of the profile and link the chess repo — completeness drives match rate.

### 3. Turing
- **Fit:** explicitly recruits Indian engineers for US-remote roles.
- **Process:** profile → automated tests (MCQ + coding) per skill → sometimes a vetting interview. Tests are real work — prep DS/algos + React/Node.
- **Tip:** Take the React, Node.js, and JavaScript tests; each badge improves matching.

### 4. Braintrust
- **Fit:** talent network (no middleman fee taken from you); you apply to posted roles after joining.
- **Tip:** Strong GitHub + clear specialization helps you stand out in the marketplace feed.

### 5. Gun.io / Toptal (stretch)
- **Gun.io:** vetted freelance, US-heavy. Worth a profile once the above are live.
- **Toptal:** very selective, generally wants 3+ years and a hard screening. Treat as a stretch goal to revisit in a year.
