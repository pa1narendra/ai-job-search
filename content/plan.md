# ai-job-search — Posting Plan (single scope)

Scope: **single** · Modes: **build-in-public** (dominant) + case-study + hiring · Goals: validation, users, gigs
Platforms: **X, LinkedIn, blog, Instagram** (skipped YouTube — no demo video yet)

## Chosen angle
**The India retarget journey:** "I forked an AI job-search agent built for Denmark, tried to make it work in India, hit a wall with Naukri/LinkedIn/Indeed, and pivoted to remote-global boards + a recency filter." It's true, relatable, and showcases judgment (good for hiring/gigs) while being directly useful to other India job-seekers (users) and inherently shareable (validation).

Structure from the dominant mode (build-in-public): a short journey with the failures kept in. Case-study layers in the problem→pivot→result spine; hiring rides along via the visible debugging/judgment. Credit upstream for the engine throughout.

## Primary CTA (don't overload it)
**"It's public — fork it if you're job-hunting from India."** (serves *users*; validation + gigs ride in the framing). Repo link in the X reply / LinkedIn first comment.

## Per-platform one-liner
- **X:** tight 3-tweet thread — mismatch hook → the failures + pivot → CTA/credit.
- **LinkedIn:** same arc as a short narrative with the lesson ("Indian portals block bots; remote-global boards + recency win"), link in first comment. Posting under own name is fine.
- **Blog:** short post — the Denmark mismatch, the three dead ends, the pivot, the recency filter, credit + repo, one takeaway.
- **Instagram:** carousel — one beat per slide (mismatch → 3 failures → pivot → recency → CTA), link in bio.

## Cross-promotion
X + LinkedIn + IG point to the blog; the blog links the repo and credits `MadsLorentzen/ai-job-search`.
