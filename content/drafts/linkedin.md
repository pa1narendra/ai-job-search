## Hook (first 2 lines, before "…see more")
I came across this open source AI job search agent and cloned it, thinking it would help me land a job.

After going through the readme I got to know it was actually built for the Danish market 🙂

## Body
They said it would work the same for any country, but honestly I didn't think it would work for us, so I thought why not change it for our market.

I pointed the scraping at Naukri, LinkedIn and Indeed, the major Indian sites Claude suggested, tried it, and got no results 😕 Turns out these sites don't allow scraping. Claude then suggested building a Playwright script to scrape them, but that would risk getting my LinkedIn account banned, so I decided not to risk it.

So I searched for an alternate and found that some remote sites allow scraping. I went with those, with a filter that the role should be open to work from anywhere in the world, not remote but only in US/EU. First it gave some older posts that weren't even related, so I added one more filter for the most recent ones, and it worked, I got some posts that are somewhat related 🙂

Just to be clear, the application engine (fit scoring, CV and cover letter tailoring, the draft and review step, and the PDF checks) is MadsLorentzen's open source framework. I only changed the search side for India.

So if you are also job hunting remote from India, the big Indian portals are mostly a dead end with the scraping blocks and old data. The remote sites that hire from anywhere worked better for me.
