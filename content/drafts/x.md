## 1/ (hook — stands alone)
I came across this open source AI job search agent and cloned it, thinking it would help me land a job 🙂 Went through the readme and got to know it was actually built for the Danish market. They said it would work the same for any country, but honestly I didn't think it would work for us.

## 2/
So I thought why not change it for our market. I pointed the scraping at Naukri, LinkedIn and Indeed, the major Indian sites Claude suggested, tried it, and got no results 😕 Turns out these sites don't allow scraping.

## 3/
Claude suggested building a Playwright script to scrape them, but that would risk getting my LinkedIn account banned, so I decided not to risk it. Searched for an alternate and found some remote sites that allow scraping, so I went with those, with a filter that the role should be open to work from anywhere in the world, not remote but only in US/EU.

[ASSET: screenshot — the remote-global results]

## 4/ (CTA + credit)
First it gave some older posts that weren't even related, so I added a filter for the most recent ones, and it worked, I got some posts that are somewhat related 🙂 The application engine (CV tailoring, draft + review, PDF checks) is MadsLorentzen's framework, I just changed the search side for India.

It's on my GitHub if you want to try it, give it a shot and let me know how it feels 👇
https://github.com/pa1narendra/ai-job-search
